# Atlas visual direction

Reference inspection: 16 November 2026. Primary identity:
[Malwarous](https://malwarous.dev/). Secondary interaction reference:
[GTT TalentArena](https://gtt-talentarena.github.io/).

Firecrawl branding, rendered screenshots and public page content were inspected.
Malwarous uses charcoal `#0E0E11`, warm text `#E7E5DF`, lavender `#9D90FF`, violet
`#3F2DB5`, and amber `#F2A93B`. Observed typefaces are Archivo, IBM Plex Sans,
and JetBrains Mono. Hairline separators, square buttons, technical labels and
network diagrams establish its identity. Reference screenshots are retained only
in ignored local QA material; no reference site code or imagery is shipped.

Atlas applies that identity to a football evidence laboratory: large editorial
headings, dark instrument panels, original signal schematics, and the existing
synthetic software video. GTT informed the ambition for an immersive introduction
and a human team section; its cream palette, copy, artwork and implementation are
not reused. Exact spacing and composition are original Atlas choices.

Motion is progressive enhancement: the content is immediately available,
decorative animation pauses offscreen, and reduced-motion preferences suppress
animation and video autoplay. Pointer treatments do not hide the normal cursor.
No loading performance, network security, probability, or model metric is invented
as decoration. Replay positions and benchmark values retain their existing data
and provenance. The visual layer does not alter inference or the submission.

Original SVG schematics are marked illustrative. Existing synthetic video and
licensed external replays retain their respective attribution. Typography is
self-hosted under the included OFL licenses.
