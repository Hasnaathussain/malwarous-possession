# Local typography

Unmodified Google Fonts releases retrieved 16 November 2026. Each typeface is
distributed under its adjacent SIL Open Font License. The browser loads these
files from Atlas itself; there are no Google Fonts browser requests.

| File | Typeface | Source |
| --- | --- | --- |
| archivo-800.ttf | Archivo, weight 800 | [Archivo](https://fonts.google.com/specimen/Archivo) |
| ibm-plex-sans-400.ttf | IBM Plex Sans, weight 400 | [IBM Plex Sans](https://fonts.google.com/specimen/IBM+Plex+Sans) |
| jetbrains-mono-400.ttf | JetBrains Mono, weight 400 | [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) |

Exact file checksums are pinned in `scripts/release_integrity.py` and the source
manifest. Original license texts come from the corresponding `ofl/archivo`,
`ofl/ibmplexsans`, and `ofl/jetbrainsmono` directories in
[google/fonts](https://github.com/google/fonts/tree/main/ofl).
